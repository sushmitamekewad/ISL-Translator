💡 Offline Operation & Edge Deployment Guide

Cloud & Edge Ready

1. Client-Side Browser (PWA + ONNX Web)

Models are exported to ONNX and run directly inside the browser using WebAssembly / WebGPU. No frames leave the user's laptop or mobile phone. Works 100% without internet!

2. Local Docker Edge Container

Spin up the container locally via docker-compose up. The local API processes streams offline on localhost with zero network latency.

3. Mobile & IoT Hardware

Convert checkpoints to TFLite or ONNX Runtime Mobile for Raspberry Pi, Android, or iOS edge deployment.
